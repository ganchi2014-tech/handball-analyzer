# Handball Analyzer

ハンドボールの試合をスマホで記録・分析するためのシンプルなWebアプリです。

コートをタップしてシュート位置を記録し、ゴール/セーブ/ミス、選手、ターンオーバー(TO)などをワンタップで集計します。

## 特長

- **コートマップ記録**: SVGコート上のタップ位置にシュート結果をプロット
- **オフェンス/ディフェンス切替**: 自チーム・相手チーム双方の攻撃を記録
- **試合タイマー** と スコアボード
- **GK切替**: 出場中のGKを切り替えてGK別セーブ率を集計
- **ダッシュボード**: 攻撃効率 / ST決定率 / GKセーブ率をリアルタイム表示
- **集約画面**: 選手別スタッツ、シュート分布チャート、ランニングスコア
- **画像エクスポート**: html2canvasで集約画面を画像保存（iOSの長押し保存にも対応）
- **PWA対応のメタ設定**: iOS/Androidホーム画面に追加してアプリ風に利用

## 使い方

1. `index.html` をブラウザで開く（モバイル推奨）
2. 試合日と対戦相手を入力
3. 出場GKを選択
4. オフェンス/ディフェンスを切り替え
5. コートをタップしてシュート結果と選手を選択
6. 「📊 データ」で集約を確認、「📸 画像として保存」で書き出し

## 構成

- `index.html` — 画面構造
- `styles.css` — スタイル
- `app.js` — 状態管理・記録・集約ロジック

外部依存:

- [html2canvas](https://html2canvas.hertzen.com/) — 画像エクスポート
- Google Fonts (Inter)

## ローカルでの起動

ビルド不要。ファイルをそのままブラウザで開けば動作します。

```sh
# 例: Python の簡易サーバー
python -m http.server 8000
# → http://localhost:8000
```
