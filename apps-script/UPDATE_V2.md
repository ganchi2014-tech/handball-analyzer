# 受け側のスクリプトを v2 に入れ替える（5分）

分析担当用アプリの記録を、同じファイルの中の「白谷」というシートにためるための入れ替えです。
生徒用アプリの送り先（URL）と、生徒のシートは変わりません。

## 手順

1. <https://script.google.com> を開き、今使っているプロジェクト（「ハンドボール送信」など）を開く
2. エディタの中身を全部消して、`apps-script/handball-submit.gs` の中身を全文貼り付け、保存
3. 右上「デプロイ」→「**デプロイを管理**」
4. 今のデプロイの ✏（編集）を押す
5. 「バージョン」を「**新バージョン**」にして「デプロイ」

**注意：「新しいデプロイ」ではなく「デプロイを管理」から入れ替える。**
「新しいデプロイ」にするとURLが変わり、生徒用アプリの送り先を直す必要が出ます。

## 確かめ方

- ブラウザで送り先のURL（…/exec）を開くと `"version":2` と出る
- 分析担当用アプリのまとめ画面で「この試合を分析用のシートに送る」を押すと、「白谷」シートができて記録が入る
- 入れ替える前に分析担当用アプリから送っても、アプリ側が止めるので生徒のシートには入らない
